## T-004 v1 — 首个 MVP 产品路径与公开名称决策

- TODO 回链：[T-004](TODO.md#t-004)
- 任务定义版本：`v1`
- 块所有者：`/root`
- 最近更新时间：`2026-08-19 Asia/Shanghai`
- 写入模式：`single-writer`。
- 执行授权：`explicit`；来源为用户本轮要求综合选择最符合独立环境与项目受控共享目的的 MVP，并授权通过 `gh` 修改已发布 GitHub 仓库名称；范围包括本地术语迁移、GitHub repository rename、remote 验证和提交，不包括可见性、权限、Topics、Release 或品牌视觉修改。
- 目的意图：把产品从候选路径收敛为由项目创建并拥有隔离实例的受管 Runtime Platform，以 VM 作为默认安全边界、软件介导的数据共享作为唯一默认共享路径；同时选择冲突更低的新公开名称并完成本地与 GitHub 仓库迁移，但不在本任务实现 Runtime、UI 或 guest agent。
- 定义对账：目标、边界和完成定义与 [T-004 v1](TODO.md#t-004) 一致；用户明确补充的隔离与共享目的用于决定候选路径，不扩大到产品实现。

### Step 1 — 冻结产品与安全边界

- 步骤开场摘要：继续“首个 MVP 产品路径与公开名称决策”，当前执行 Step 1，目标是确定最符合用户目的的产品模型；先把隔离目标转成威胁边界，再比较 VM/container/已有 Runtime 控制面，最后记录可验收的冻结结论。
- 本步产出：产品定位、隔离边界、默认共享策略、MVP 范围和明确排除项。
- 完成判据：方案直接满足“实例独立、外部应用默认不可干扰、共享由项目控制”，并清楚说明宿主管理员权限、平台许可等无法由软件消除的边界。
- 边界：不实现 Runtime；不承诺所有 host/guest 组合。
- 风险标注：隔离是相对威胁模型，不得宣传为能抵御宿主 root/管理员或平台内核失陷。
- 所需确认依据：用户已明确给出目的并授权综合选择；无需再次确认。
- 状态：`已完成`
- 实测结果：基于用户的独立实例与项目受控共享目的，已选择 Managed Runtime Platform；以一 Environment 一 VM 为默认安全边界，container 降级为 VM 内工作负载优化，默认关闭宿主共享、环境间通信和入站端口。威胁模型明确不覆盖宿主 root/管理员、内核/hypervisor 失陷和同用户恶意非沙箱进程直接篡改磁盘文件；完整基线见 `docs/architecture/mvp-baseline.md` 与 `D-002`。

### Step 2 — 选择新名称并核验迁移目标

- 步骤开场摘要：继续“首个 MVP 产品路径与公开名称决策”，当前执行 Step 2，目标是选出可公开使用的新仓库名；先生成符合独立环境语义的候选，再核验 GitHub、软件包和公开网页冲突，最后确定仓库 slug 与标准产品名。
- 本步产出：候选对比、冲突证据、标准产品名与仓库 slug。
- 完成判据：新名称不存在已发现的明显同类软件冲突，拼写清楚，并明确商标初筛不等于法律结论。
- 边界：不购买域名、不注册商标、不创建组织。
- 风险标注：公开搜索无法证明全球商标可用。
- 所需确认依据：用户已授权直接改名；无需再次确认。
- 状态：`已完成`
- 实测结果：已选择标准产品名 `Envisle` 与 repository slug `envisle`。重命名前 `sqmw/envisle` 返回 HTTP 404，GitHub 精确名称搜索为空，npm/PyPI 精确包名返回 404，Cargo 搜索无结果，公开网页精确搜索未发现同名软件；该结论是工程初筛而非正式商标意见。候选与旧称映射记录在 `docs/research/name-selection.md` 和 `D-003`。

### Step 3 — 执行本地与 GitHub 名称迁移

- 步骤开场摘要：继续“首个 MVP 产品路径与公开名称决策”，当前执行 Step 3，目标是让项目内外名称一致；先更新项目术语和索引，再提交可回退的本地变更，最后用 `gh` 重命名远端并校准 origin。
- 本步产出：项目文档术语迁移、迁移 Decision、Git 提交、GitHub 新 URL 与正确 remote。
- 完成判据：旧名称只保留在显式迁移/历史来源中；新 URL 可读取；origin 指向新 URL；仓库可见性与权限未改变。
- 边界：不移动本地目录；不修改 GitHub 可见性、权限、Topics 或 Releases。
- 风险标注：旧 GitHub URL 依赖 GitHub 重定向，不能作为永久外部契约。
- 所需确认依据：用户本轮明确授权通过 `gh` 修改。
- 状态：`进行中`
- 实测结果：待执行。
